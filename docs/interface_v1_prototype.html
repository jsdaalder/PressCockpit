Your current stories, what needs attention, and what to do next.

This version shifts Overview away from a busy technical dashboard. Active reporting projects are now the main object on the screen. Workflow risk, trust review, and admin work still matter, but they support story work instead of competing with it.

Open-source portability constraint Future release for other journalists still requires reproducible workspace setup and config that does not depend on Jan-specific assumptions.

This is still a cheap planning artifact, not final visual design. Its job is to make the UX direction concrete enough that the next SwiftUI pass can implement one opinionated Overview instead of another generic dashboard.
