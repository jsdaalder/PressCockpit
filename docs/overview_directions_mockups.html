Three concrete mockups for the same Overview structure.

These mockups keep the same four building blocks: Active Projects, Suggested Next Actions, Operations, and New Work. The deliberate variable is visual direction. Each version also includes Quick Capture as the fast path for urgent notes, pasted text, and uploads that can be connected later.
